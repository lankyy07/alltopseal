How to Measure a Gasket

Use these diagrams as a measurement checklist. If dimensions are uncertain, send a clear photograph, old gasket or equipment drawing with your RFQ.

Circular Gasket

  1. Measure outer diameter (OD).
  2. Measure inner diameter (ID).
  3. Measure material thickness.
  4. State quantity and material if known.

Full-Face Gasket

  1. Measure OD and ID.
  2. Measure bolt-hole diameter.
  3. Count bolt holes.
  4. Measure PCD.
  5. Measure thickness.

Rectangular Gasket

  1. Measure overall length and width.
  2. Measure internal opening(s).
  3. Measure border width.
  4. Measure bolt-hole diameter and quantity.
  5. Measure spacing / pitch.
Not sure about PCD? Send the old gasket or a clear drawing / photograph. We can tell you which additional dimensions are needed before quotation.
